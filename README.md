# SkillGap

Skill gap analysis, career matching and personalised learning roadmaps.

The app lives in [`Skill-gap-analyzer-main/`](Skill-gap-analyzer-main/) — see its [README](Skill-gap-analyzer-main/README.md) for setup, architecture and how roadmap generation works.

```bash
cd Skill-gap-analyzer-main
npm install
npm run dev
```
